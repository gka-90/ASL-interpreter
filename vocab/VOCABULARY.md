# ASL Vocabulary (240 words)

Chosen from words that appear in both WLASL and ASL Citizen, with at least 30 video clips each (30–134 per word, about 10,900 clips in total). Picked so the words can be combined into everyday sentences.

Some signs have more than one version in the data (for example DOG1–DOG4). Each word is one class, so any version counts.
